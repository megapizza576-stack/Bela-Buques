# Bela Buquês 🌹

Landing page da **Bela Buquês**: buquês de cetim artesanais em Uberlândia, com pedidos direto pelo WhatsApp.

## O que tem nesta pasta

| Arquivo | Para que serve |
|---|---|
| `index.html` | O site inteiro (as fotos já estão dentro dele) |
| `img/` | Imagem de compartilhamento no WhatsApp/Facebook, ícones do site e cópia das fotos |
| `404.html` | Página bonita para endereço errado |
| `robots.txt` | Libera o Google para mostrar o site nas buscas |
| `.nojekyll` | Arquivo vazio que faz o GitHub publicar o site do jeito que ele está |
| `COMO-EDITAR.txt` | Como trocar fotos e textos depois que o site estiver no ar |

## Como colocar no ar (GitHub Pages)

1. Entre em **github.com** e clique em **New** (novo repositório).
2. Dê um nome, por exemplo **`belabuques`**, deixe como **Public** e clique em **Create repository**.
3. Na tela seguinte, clique em **uploading an existing file**.
4. Abra a pasta `bela-buques` no seu computador, **selecione tudo o que está dentro dela** (inclusive a pasta `img` e o arquivo `.nojekyll`) e **arraste para a página do GitHub**.
   > Arraste o **conteúdo** da pasta, não a pasta em si. O `index.html` precisa ficar na "raiz" do repositório.
5. Clique em **Commit changes**.
6. Vá em **Settings → Pages**. Em **Branch**, escolha **`main`** e **`/ (root)`** e clique em **Save**.
7. Espere 1 a 2 minutos. O site fica no ar em:
   **`https://SEU-USUARIO.github.io/belabuques/`**

## Depois de publicar

- **Teste no celular** abrindo o endereço com `?cliente` no final, para ver exatamente como o cliente vê.
- **Prévia do link no WhatsApp:** para a foto aparecer quando alguém compartilhar o link, abra o site com `?editar` no final, toque em **Baixar site** e suba de novo o `index.html` baixado (Add file → Upload files). O site completa sozinho o endereço da imagem de compartilhamento.
- Para trocar fotos e textos, veja o **`COMO-EDITAR.txt`**.
